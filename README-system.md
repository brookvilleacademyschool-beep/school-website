## Important limitation

GitHub Pages is static hosting. This system demonstrates login, vacancies, applications, staff records and permissions using browser `sessionStorage` and `localStorage`. The visible HTML or JavaScript can be inspected, passwords are not secure, and browser data is not shared across users.

A real school deployment requires a server, database, password hashing, authentication, access-control enforcement, audit logs, secure application uploads, and privacy/compliance controls. HR and applicant records should never be handled as a public static demo.
